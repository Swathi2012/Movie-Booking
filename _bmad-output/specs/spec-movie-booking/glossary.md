# Movie Booking Glossary

- Movie: a film entry with metadata such as title, description, language, runtime, genre, and poster.
- Theatre: a venue or location where one or more screens exist.
- Screen: the physical auditorium or room where a movie is shown.
- Showtime: a scheduled screening instance for a movie at a specific theatre and screen at a time.
- Seat: an individual seat position in a screen layout that can be available, selected, or booked.
- Booking: a customer reservation tied to a specific showtime and selected seats.
- Customer: an end user who browses movies and completes booking actions.
- Admin: a privileged user who manages catalog and operational data.
- JWT: a signed authentication token used to prove user identity on protected API routes.
- Availability: the current state of a seat or showtime as open for booking or already reserved.
